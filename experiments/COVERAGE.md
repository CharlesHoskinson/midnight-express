# PoC-core coverage

Every core ID has an explicit record. Done means the cited test or measured scenario exercises the implemented sentence. Partial is not done. Unit tests prove only their fixtures; short local runs are not production evidence. The canonical criteria are the supplied POC_CORE and reconciled Prototype values.

## Limits and dependencies

Real Rust libp2p 0.57 / GossipSub 0.50 (vendored custom v1.2 selector and flush counters), v1.2, TCP/Noise/Yamux. AdmissionProof is replaceable. StandInRln preserves layout, content binding, quota relation, nullifiers and recovery, but verifiers know member secrets and can link/forge. CPU cost is an explicit busy-wait, scaled from 4500us to 1500us at 200 nodes on six cores. MockLedger enforces 6s slots, 3-block finality, 1000000-byte block usage, 50000-byte state-write budget, 1048576-byte transaction cap, 256-byte Misc payload, 1024-byte emitted-log cap, 600-block pool longevity and <=1209600s intent TTL. No Compact, DUST pricing, real Indexer or network-generation claim.

Direct extra crates: curve25519-dalek supplies reviewed scalar arithmetic already used by Ed25519; subtle supplies constant-time proof comparison; rand_chacha supplies seeded schedules; serde_json supplies fixed checker artifacts; async-trait supplies replaceable async ingress/retrieval traits; aho-corasick supplies a cached binary multi-pattern canary scanner. All other listed dependencies are brief-listed crates. No custom primitive and no unsafe.

The node receipt and store allocation are volatile. Accepted feed and observation caches now have explicit caps/retention; exhaustive all-cache/RSS soak proof remains absent. Backfill page size is additionally constrained by 65536-byte CBOR frame cap; byte arrays currently encode as CBOR integer arrays, with roughly 2x wire overhead. Initial cohort exemption and expiry reconstruction follow PROTOTYPE F1/F2, and are explicitly qualified.
