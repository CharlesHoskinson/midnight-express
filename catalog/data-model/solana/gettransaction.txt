getTransaction
Copy Markdown
Open
Returns a confirmed transaction by signature, or 
null
 if it is not found at
the requested commitment.
Source
get_transaction
params
string
required
Transaction signature, as base-58 encoded string
string | object
optional
Either a configuration object or, for backwards compatibility, a bare encoding
string. Prefer the object form.
Passing a bare encoding string as the second positional parameter is
deprecated. Use the configuration object instead.
When this parameter is an object, it may contain the following fields:
commitment
string
maxSupportedTransactionVersion
number
encoding
string
result
object | null
Returns 
null
 if transaction is not found or not confirmed, otherwise returns
an object containing:
This top-level response uses the shared

Confirmed Transaction Responses

structure.
blockTime
i64 | null
meta
object | null
slot
u64
transaction
object | string | [string,encoding]
version
"legacy" | number
