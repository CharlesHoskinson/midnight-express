blockSubscribe
Copy Markdown
Open
Subscribe to receive notifications when a new block reaches 
confirmed
 or

finalized
 commitment.
Source
block_subscribe
Unstable Method
Agave documents this as an 
unstable RPC PubSub 
blockSubscribe

subscription
.
It is only available if the validator was started with

--rpc-pubsub-enable-block-subscription
, which also requires

--enable-rpc-transaction-history
.
params
string | object !required
optional
Filter describing which blocks should produce notifications.
all
 returns every matching block
{ "mentionsAccountOrProgram": <pubkey> }
 returns only blocks that contain a
transaction mentioning the provided base-58 encoded address
object
optional
Optional configuration object.
commitment
string !values confirmed finalized !default finalized
encoding
string !values binary base58 base64 json jsonParsed !default base64
transactionDetails
string !values full accounts signatures none !default full
maxSupportedTransactionVersion
number
showRewards
bool !values true false !default false
result
integer
Subscription id. Pass this to

blockUnsubscribe
.
