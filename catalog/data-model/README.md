# Unified model literature archive

Five independent research roles collected primary-source literature using Scrapling: event contracts, domain modelling, financial semantics, semantic constraints and safe agent actions. Two additional chain studies extend the application vocabulary for Ethereum and Solana.

- [Event contracts study](../../reviews/data-model/event-contracts.md)
- [Domain modelling study](../../reviews/data-model/domain-modelling.md)
- [Financial semantics study](../../reviews/data-model/financial-semantics.md)
- [Semantic constraints study](../../reviews/data-model/semantic-constraints.md)
- [Safe agent actions study](../../reviews/data-model/safe-agent-actions.md)

[index.json](index.json) consolidates 140 fetch records (not unique publications), with 253 archived-file SHA-256 checks and 0 mismatches. Each role retains its own full manifest, scripts and extracted source texts. Review individual manifests for resolved URLs, fetch status, extraction and TLS caveats. Failed/empty responses and unverified TLS exceptions are explicitly recorded; hashes establish local integrity, not publisher authentication. These private research artifacts are not included in the public GitHub Pages subtree.
