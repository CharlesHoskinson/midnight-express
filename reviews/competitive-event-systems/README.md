# Three-agent event-system review

Three independent agents studied **each of 26 systems**, giving **78 reviewer/system studies**, before the findings were added to this repository. NEAR's standard and Lake indexing were considered together; local DOM and Node listener designs have individual coverage entries. Reviews have independent architecture/delivery, privacy/security and product/developer-experience lenses; independent reviews are not a claim of independent security audits.
