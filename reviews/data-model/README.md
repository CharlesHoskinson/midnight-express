# Five unified-model research perspectives

Each researcher used Scrapling to archive primary literature and wrote an independent design study:

1. [Event contracts](event-contracts.md): CloudEvents, JSON Schema, AsyncAPI, canonicalization and schema evolution.
2. [Domain modelling](domain-modelling.md): bounded contexts, canonical integration models, UBL and governance.
3. [Financial semantics](financial-semantics.md): FINOS CDM, FpML, UBL, quantities, prices, parties and settlement distinctions.
4. [Semantic constraints](semantic-constraints.md): closed shapes, vocabularies and optional offline semantic export.
5. [Safe agent actions](safe-agent-actions.md): language-theoretic parsing, least privilege and exact capability binding.

Original synthesis: [unified data model](../../docs/product-requirements/unified-data-model.md). Archive/integrity index: [catalog/data-model](../../catalog/data-model/README.md). Narrow executable reference: [model](../../model/README.md). Additional Ethereum and Solana studies extend the application domain without expanding the universal core.
