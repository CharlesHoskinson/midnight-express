# Ten-agent architecture page study

The nine Markdown reports in this directory cover system composition, event flow, admission, privacy, recovery, authority, SDK semantics, product priorities and page accessibility. A tenth agent generated two conceptual illustrations with built-in GPT image generation; its deliverables and exact prompts are preserved in `../../website/dist/assets/image-prompts.json`.

Reports describe the source state at review time. Early missing use-case-data and absent-script findings were fixed during assembly. Final integration separates parallel anchor production, proposes rather than claims atomic Umbra processing, shows OpenMLS at both endpoints, connects controls to accessible panels and preserves explicit acknowledgement policy.
