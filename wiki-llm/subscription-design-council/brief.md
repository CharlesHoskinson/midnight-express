# Subscription workspace design brief

The user confirmed that a feed directory for discovering and organizing subscriptions should be the default view. A personal inbox and delivery console support that workflow.

The council consists of distinct reviewers from Grok, Gemini, GPT and Claude. Research must ground recommendations in public primary sources fetched with Scrapling and screenshots inspected through PixelRAG. Reviewers inspect the current demo and preserve its protocol boundaries. Model invocations and report hashes are recorded in provenance.json; queued work is not a completed review.

The directory must support hundreds of synthetic feeds, useful search and durable organization. Feed discovery, event reading and delivery operations need clear relationships. Saved preferences must not recreate wallet permission or protocol authority. Consensus will distinguish familiar interface patterns from protocol capabilities still requiring implementation.
