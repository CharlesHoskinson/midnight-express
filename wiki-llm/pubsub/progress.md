# Research progress and approach

## Initial investigation

The surge began from main commit `5ff9627`. Assignments covered human experience, agent standards, wallet consumers, subscription contracts, stack feasibility, privacy, data usefulness, durable lifecycle, demonstration product design and independent criticism. Distinct researchers used the requested provider/model mix. Source collection used Scrapling and PixelRAG CDP tiles; CPU screenshots were inspected without claiming a GPU search index.

## Evidence that changed the design

The initial wallet routing table used business-topic language. It was corrected to whole-shard intake followed by locally authorized selection. Current MCP documents required a versioned adapter using explicit handles and notification invalidation rather than treating a notification connection as a durable subscription.

Actual model validation established which fixed-context events can support the demonstration. Contracts and credentials remained mocks. Rejected inputs could not be allowed to poison the occurrence index. Public reference fixtures now bind validator results to event and context hashes, including the rejected expired quote.

Moth source inspection showed that an origin grant exposes more capabilities than this adapter uses. Independent studies confirmed the shared GitHub Pages origin and connector activity refreshing auto-lock. The demonstration therefore requires acknowledgement before Connect and performs no background wallet calls.

## Implementation and review

The demonstration introduced bounded local scheduling, explicit gaps, retained replay, immutable scope revisions, permission changes, occurrence suppression and local review. Review found races in pending wallet connections, state guards after revocation, paused saturation, gap recovery and rejected-input bookkeeping. Those findings produced fixes and meaningful permanent tests.

The private local control-plane schema remains separate from installed business profiles and the original wire. Browser-exported intents were checked against that schema. Received host progress, delivered inbox progress and processed dispositions remain distinct. No effect, source finality or durable database integration is inferred from those fields.

## Provider execution limits

Initial external researchers reached tool-turn limits while collecting evidence. They continued with the same requested models and saved captures; no provider was substituted. The later Grok coordinator was interrupted with exit 143 after two reports and their visual appendices were written, before it could record completion metadata. The independent critic was continued separately to finish its report. Provider provenance preserves interrupted runs and distinguishes report artifacts from successful process exit.

## Convergence

The working synthesis is a private local watch service and durable consumer journal above existing transport, with optional versioned interoperability adapters. Source snapshots and agent reports preserve dissent about origin isolation, version pins, consumer wording, independent model interpretation and remaining protocol acceptance work. Final decisions and their limits are recorded separately from this progress history.
